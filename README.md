## Repository Structure

Each problem is stored in its own directory using the LeetCode problem number and title.

```text
leetcode-solutions/
│
├── 1-two-sum/
├── 83-remove-duplicates-from-sorted-list/
├── 153-find-minimum-in-rotated-sorted-array/
└── README.md
```

Solutions are synced automatically using **LeetSync**, including the runtime and memory performance reported by LeetCode.
